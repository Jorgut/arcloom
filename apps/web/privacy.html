隐私说明

最后更新：2026-11-03

上线前需补齐：请在开放投稿前写明实际运营主体、联系邮箱、数据托管地区和适用法律。未完成前，投稿接口默认关闭。

我们收集什么

公开浏览目录不要求创建账户。收藏只保存在当前浏览器的本地存储。只有当在线投稿功能启用并且你主动提交时，Arcloom 才会接收资源名称、公开来源链接、可选推荐理由、许可确认，以及为防止滥用而生成的 IP HMAC 摘要。原始 IP 地址不会写入投稿表。

使用目的与保存

投稿数据仅用于来源核验、授权沟通与目录审核。投稿由运营方配置的 Supabase 项目保存；运营方需要设定并公开具体保存期限和删除请求流程。审核结束且不再需要时，应删除投稿记录及关联的 IP 摘要。

第三方服务

网站部署在运营方配置的托管服务上。投稿功能启用后，表单数据会传到对应的 Supabase 项目。当前页面不嵌入广告或分析 SDK。实际启用服务或分析工具前，应更新此说明。

你的选择

你可以不使用投稿功能。投稿不授予 Arcloom 复制、销售或再许可该资源的权利。数据访问、更正或删除请求请联系：[上线前填写运营联系邮箱]。
